# Rejected repair cycle

This first focused v0.6.0 cycle is retained only as failure evidence. Trial 3
changed a five-minute interval to four minutes, so the candidate was rejected.

The exact skill snapshot was not archived when this experiment ran and cannot
be reconstructed to the `skill_sha256` recorded in its generation metadata.
Do not use this directory as reproducible release evidence. Cycle 2 and the full
regression archive their exact skill text, and the final candidate suite requires
fresh generation for both configurations.
